# BNU 近代物理实验报告工作区

本仓库用于整理北京师范大学近代物理实验课程的实验讲义、预习报告和实验报告。实验资料按讲义中的内部标题分类保存，每个实验拥有独立的资料和报告目录。

## 工作区文件

- [`AGENT.md`](AGENT.md)：工作区操作约定，包括 Git 提交、验证和实验目录规范。
- [`agents.md`](agents.md)：面向报告写作的总体协作规则和持续整理规则。
- [`preview.md`](preview.md)：近代物理实验预习报告要求。
- [`report.md`](report.md)：物理实验报告内容、格式和排版要求。
- `物理学报模板_Acta_Physica_Sinica_/`：LaTeX 排版参考模板及相关资源。

## 实验资料

每个实验的目录结构统一为：

```text
实验标题/
├── 实验标题.pdf
├── preview_report/    # 预习报告
└── lab_report/        # 实验报告
```

当前已整理的实验包括：

1. 光纤的物理性质与应用
2. 铷原子的光泵磁共振实验
3. 液晶物性
4. 干涉滤光片的镀制
5. 塞曼效应
6. He-Ne 激光的纵横模分析和模分裂
7. 高温超导材料的特性与表征
8. 光学多道与氢氘同位素光谱
9. 非线性电路混沌及其同步控制

PDF 文件已根据文档第一页显示的内部标题重命名，并放入对应的同名目录中。

## 报告编写流程

1. 阅读对应实验目录中的 PDF 讲义，提取实验目的、原理、方法、实验内容和思考题。
2. 在该实验的 `preview_report/` 中编写预习报告，内容遵循工作区根目录的 [`preview.md`](preview.md)。
3. 在该实验的 `lab_report/` 中编写实验报告，内容遵循工作区根目录的 [`report.md`](report.md)。
4. 预习报告和实验报告均使用 LaTeX 编写，优先使用 XeLaTeX 或 LuaLaTeX 编译中文文档。
5. 编译辅助文件集中放入构建目录，最终 PDF 保存在对应的报告目录中；完成后检查编译日志、中文排版、公式、图表和参考文献。
6. 不得编造实验数据、实验现象、误差或结论；缺少实验数据时应明确标注待补充。

## 预习报告要点

预习报告应简述：

- 实验目的；
- 物理原理、实验原理和仪器原理；
- 实验方法与主要实验内容；
- 第一次课后留的问题和实验思考题；
- 对实验的思考、理解以及对实验内容的掌握。

## 实验报告要点

实验报告采用以下结构：

1. 实验题目及学号、姓名、指导老师、实验日期；
2. 摘要（100—200 字，包含目的、方法、主要结果和主要结论）；
3. 一、引言；
4. 二、原理；
5. 三、实验；
6. 四、结果与分析讨论；
7. 五、结论和建议（总结）；
8. 六、参考文献。

报告中的图、表和公式应统一编号，并标明图表题、物理意义、单位和公式符号。实验结果应结合图表和文字分析规律，与理论预期比较，讨论误差来源及改进方法。
