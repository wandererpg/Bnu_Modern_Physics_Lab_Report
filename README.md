# 近代物理实验报告工作区

本工作区依据实验讲义、真实测量记录和课程要求，生成可复现的实验报告：LaTeX 源文件、PDF、数据处理脚本和图表。用户可以直接描述任务；Agent 应先查阅材料，再询问影响结果的关键缺口。

## 1. 快速开始

把讲义、测量表和实验图片放入对应实验目录，然后发送类似请求：

> 请根据“塞曼效应”目录中的讲义和实测数据完成实验报告，使用统一 minimal 模板，交付 LaTeX 和 PDF。先检查已有材料，主动询问缺少的关键事实，其余按默认配置推进。

已有报告可以直接指定文件：

> 请修改“实验标题/lab_report/lab_report.tex”，沿用当前模板和已有内容，更新结果分析并编译 PDF。缺少数据或峰位配对依据时向我提问。

目录、模板和交付范围均可修改。只要求实验报告时，保留预习报告目录，不自动扩大到预习报告撰写。

## 2. 统一最小实验报告模板

新报告统一采用 `minimal`，将已验证的最小 LaTeX 基础与实验报告内容要求结合：XeLaTeX、标准 ctexart、Fandol/Latin Modern 字体、标准章节命令和 `1`、`1.1` 编号，A4 单栏、11pt、25mm 页边距及约 1.5 倍行距。

正式骨架保留两行基本信息、校徽、中文摘要与关键词、引言、原理、结果与分析讨论、实验总结、参考文献，以及文献后的英文摘要与关键词。直接在 `lab_report/lab_report.tex` 填写；骨架中的待补充内容不代表报告已完成。

[模板说明](skills/Lab_Workflow_Generator/assets/report_templates/README.md)说明安装与编辑方式；[分项诊断](skills/Lab_Workflow_Generator/assets/minimal_latex/README.md)用于检查引擎、字体和编号。注册表仅登记当前 `minimal`；原六套样板保留为旧报告兼容资料，不再作为新报告推荐选择。已有报告不会自动换版，迁移前须核对全部正文、数据、文献和手动修改。

教师明确规定格式时，在稳定编译基础上调整，保留报告内容要求。

## 3. 默认配置与可修改配置

以下为使用概览；详细内容标准以 [report.md](report.md) 为准，协作与权限规则以 [agents.md](agents.md) 为准。

| 配置项 | 默认行为 | 如何修改 |
| --- | --- | --- |
| 工作范围 | 按请求完成实验报告，每项实验独立建目录 | 指定实验名称、已有主文件，以及是否同时生成预习报告 |
| 模板 | 新报告统一 minimal，旧报告保留已有内容 | 可要求迁移到新模板；教师明确要求的格式优先 |
| 语言与摘要 | 中文正文；中文摘要和关键词在前，英文摘要及英文关键词紧接参考文献之后 | 提供教师规定的语言、摘要长度等要求 |
| 章节 | 引言、原理、结果与分析讨论、实验总结、参考文献 | 提供课程指定结构；一般结构细节按 report.md 执行 |
| 页面与样式 | A4；栏式、字体、字号与行距随模板 | 指定字体、页边距、栏式、篇幅或提交格式；Agent 复核修改后的版面 |
| 图表 | 中文图表标题与正文引用，按真实数据绘制，尺寸适配当前栏宽 | 指定散点、折线、误差棒、拟合、局部放大、配色及图片组尺寸 |
| 数据处理 | 保存原始记录，区分实测、计算、理论与估计值 | 提供校准参数、单位、拟合模型或筛点依据；筛点另存审计记录 |
| 基本信息 | 作者/学号与指导老师/实验时间分两行；缺项保留填写横线 | 提供姓名、学号、老师和实验日期 |
| 草稿与附录 | 初始骨架标记为草稿，附录默认关闭；实验数据单独保存在本地 | 核实内容后移除草稿标记；有必要时启用程序、推导等非实验数据附录 |
| 编译与交付 | XeLaTeX；使用文献库时配合 BibTeX；交付源文件和 PDF，缓存集中在 build/ | 指定目标路径及额外交付物；骨架生成不能代替完整报告 |

当前结构还包括：引言两段分别介绍背景和实验内容；原理下设实验原理、实验装置、实验方法，方法按步骤细分；文献采用上角标引用。中文摘要首次涉及元器件、物质等英文术语时写中文名称，括号注明英文名称及缩写，正文随后可使用缩写。摘要长度、关键词数量等完整要求见 [report.md](report.md)。

**参数改在哪里**：

- 基本信息、摘要、正文和文献：直接编辑 `lab_report/lab_report.tex`。
- 当前模板：新建时省略 `--template` 或传入 `--template minimal`；选择记录位于 `lab_report/template_selection.json`。
- 版式：在本份报告主文件中调整已核对的导言区设置；不要复制整套旧导言区覆盖新模板。
- 编译和日志：工作流的 `--stage compile` 使用 `build/run-<唯一标识>/`，成功后更新报告目录 PDF。
- 阶段：根据本次改动选择 `--stage`，避免为小改动重跑数据与全部生成流程。

实验数值、测量现象、误差来源和引用依据属于事实输入，不能作为可随意设置的排版参数。

## 4. 用户需要提供哪些信息

材料可以分批提供。Agent 应先从文件和已有对话中提取信息，按实际缺口提问。

| 信息 | 推荐提供方式 | 缺失时的处理 |
| --- | --- | --- |
| 实验身份与任务范围 | 实验标题、目录或已有报告路径；说明新建、修改或切换模板 | 从讲义标题和路径识别；多个实验无法区分时询问目标 |
| 讲义与课程要求 | PDF、教师模板、评分标准或要求截图 | 可先整理已有报告；缺少方法或必需格式依据时索取材料 |
| 原始数据与单位 | Excel、CSV、仪器导出或清晰记录照片；说明列含义、单位与重复次数 | 可完成骨架和有依据的理论内容；结果与结论标记待补充 |
| 数据解释与校准 | 峰位配对、角度零点、换算系数、仪器量程/精度及来源 | 影响换算、拟合或不确定度时必须询问；保留原始值 |
| 装置、方法与现象 | 接线/装置照片、实际步骤、观察记录与异常情况 | 区分讲义规定方法和实际操作；实际记录缺失时索取 |
| 图片与文献 | 原图与图意说明；讲义参考文献、论文信息或可核查来源 | 复用已核实素材，缺少支撑时标注；引用只使用可核实来源 |
| 基本信息与偏好 | 姓名、学号、老师、日期；模板与排版偏好 | 基本信息留横线；样式采用默认或已有配置，不阻塞独立工作 |
| 完成条件 | 正式 PDF、截止时间、篇幅及需特别检查的图表 | 默认交付源文件与 PDF；范围不清且影响交付时询问 |

扫描件须保证文字、单位和小数点可辨认。判断异常点时应结合重复测量、峰位判读或仪器异常记录；仅凭点偏离折线不能认定测量错误。

## 5. 完成实验报告的工作流

| 步骤 | Agent 的操作 | 本步完成条件 |
| --- | --- | --- |
| 1. 明确任务 | 识别任务、上下文、约束、完成条件；读取课程要求与相关规则 | 实验、交付范围、现有状态及关键缺口已确定 |
| 2. 整理材料 | 核对讲义、原始记录、图片和文献；确认单位、来源与实际操作 | 材料可追溯，必要问题已提出，事实与假设分开记录 |
| 3. 选择模板 | 依选择顺序部署模板或沿用旧报告；必要时保存历史副本 | 主文件和依赖齐全，已有内容完整，选择明确 |
| 4. 处理数据 | 用脚本换算、拟合、绘图和生成必要表格，保存处理依据 | 输出可复现，单位与有效数字核对，原始记录保留，异常值处理可审查 |
| 5. 写作与整合 | 完成正文、摘要、图表解释、实验总结与文献 | 主要结论有依据，中英文一致，缺项明确标记 |
| 6. 检查与编译 | 按 report.md 定向检查，编译与解析引用，查看日志和渲染 PDF | 引用已解析，内容符合要求，相关页无裁切、重叠或明显尺寸问题 |
| 7. 交付 | 给出源文件、PDF、处理脚本和数据说明路径，简述结果与待补项 | 满足完成条件；材料不足时准确交付草稿与缺口清单 |

### 命令入口

在工作区根目录执行，Python 需为 3.10+；本机可用 `py -3.12` 代替下列 `python`。需要 XeLaTeX 和对应 LaTeX 包；按数据与脚本需要安装 NumPy、Matplotlib、openpyxl 等依赖。

```powershell
# 查看模板，不创建报告
python skills/Lab_Workflow_Generator/scripts/select_report_template.py --list-templates

# 新实验部署骨架，示例使用 minimal；尚未生成真实报告内容
python skills/Lab_Workflow_Generator/scripts/run_lab_workflow.py --workspace . --experiment "实验标题" --stage scaffold --template minimal

# 查看材料与报告状态
python skills/Lab_Workflow_Generator/scripts/run_lab_workflow.py --workspace . --experiment "实验标题" --stage status

# Agent 完成数据处理和正文后，执行相关检查与编译
python skills/Lab_Workflow_Generator/scripts/run_lab_workflow.py --workspace . --experiment "实验标题" --stage check
python skills/Lab_Workflow_Generator/scripts/run_lab_workflow.py --workspace . --experiment "实验标题" --stage compile
```

其他阶段和参数以脚本 `--help` 为准。脚本负责确定性步骤，Agent 负责读取材料、写作、事实核对与版面审查。`--force` 涉及讲义状态检查，不作为常规调用参数，也不用于绕过模板防覆盖保护。编译成功只是验收的一部分。

## 6. Agent 自主提问与信息补全指引

开始报告任务时读取[运行规范](运行规范.md)、[项目规则](agents.md)和[报告要求](report.md)；选择或切换模板时再查[模板库说明](skills/Lab_Workflow_Generator/assets/report_templates/README.md)。

1. **先查材料**：读取指定文件、相关讲义、已有报告与选择记录，沿用已经确认的决定。
2. **区分事实与配置**：模板、图表布局及可逆排版决策按默认或最小合理假设直接推进，简短说明假设。测量数据、单位、实验现象、峰位对应关系与校准依据缺失时，不用假设补造。
3. **合并关键问题**：只询问会实质改变正确性、范围或权限的信息。注明对应文件/列/图、缺少什么，以及答案影响哪个结果；存在多种解释时可提供简短选项。
4. **继续独立工作**：等待答复时暂停依赖答案的计算或结论，继续整理材料、设置模板及完成有依据的部分。没有答复不能视为确认。
5. **收敛缺口**：在实验目录的数据说明或报告 README 中记录来源、假设、待补项与受影响章节。收到补充材料后更新相关计算、正文与图表，做匹配的局部校验。
6. **核对完成条件**：关键事实未补齐时交付明确标记的草稿。正式报告须完成内容检查、编译与 PDF 版面复核；移除草稿标记时确认占位内容已全部处理。

例如：

> “数据.xlsx”B、C 列未注明单位。它们是否分别为左、右峰时间，单位为 ms？该解释用于计算频差；确认前先完成模板与讲义原理部分。

> 当前记录只有单次测量，且未找到仪器精度。请提供仪器型号/分辨率或误差说明，以便确定不确定度依据；目前先保留实测值和单位。

可提供任务卡，也可用普通语言描述，由 Agent 整理：

```text
任务：新建 / 修改 / 切换模板；实验名称与目录：
上下文：讲义、原始数据、图片、已有报告的位置：
约束：教师要求、指定模板、排版偏好、需保留的内容：
完成条件：交付物、篇幅/截止时间、需重点核对的结果或图表：
基本信息：姓名、学号、指导老师、实验日期（可后补）：
```

## 7. 文件组织与文档入口

```text
<实验标题>/
├── <实验标题>.pdf                 # 实验讲义
├── preview_report/                # 预习报告源文件与 PDF
└── lab_report/
    ├── lab_report.tex             # 单文件填写信息、摘要、正文和文献
    ├── lab_report.pdf             # 正式或明确标记的草稿 PDF
    ├── template_selection.json    # 模板选择记录
    ├── assets/bnu_logo.png        # 首页校徽；缺失时标明待补充
    ├── data/                      # 原始/处理数据与来源说明
    ├── figures/                   # 图表
    ├── scripts/                   # 可复现处理脚本
    ├── tables/                    # 按需生成的表格片段
    └── build/                     # 编译辅助文件
```

旧报告可沿用已有文件布局。原始数据和完整数据表单独保存在本地；正式报告不设实验数据附录，正文只保留支撑分析所需的图表。
