# BNU 近代物理实验报告工作区

本仓库用于整理北京师范大学近代物理实验课程的实验讲义、预习报告和实验报告。实验资料按讲义中的内部标题分类保存，每个实验拥有独立的资料和报告目录。

## 工作区文件

- [`AGENTS.md`](AGENTS.md)：适用于整个工作区的操作约定、目录规范、数据真实性要求和协作规则。
- [`preview.md`](preview.md)：近代物理实验预习报告要求。
- [`report.md`](report.md)：物理实验报告的内容、数据处理、格式和排版要求。
- `物理学报模板_Acta_Physica_Sinica_/`：LaTeX 排版参考模板及相关资源。

## 实验资料

每个实验的目录结构统一为：

```text
实验标题/
├── 实验标题.pdf
├── preview_report/    # 预习报告
└── lab_report/        # 实验报告
    ├── <报告源文件>.tex
    ├── <报告文件>.pdf
    ├── figures/        # 数据图、拟合图和其他插图（按需）
    ├── data/           # 原始数据、处理结果及数据说明（按需）
    ├── <数据处理脚本>.py  # 可复现的数据处理与作图脚本（按需）
    └── build/         # LaTeX 编译辅助文件
```

## 报告编写流程

1. 阅读对应实验目录中的 PDF 讲义，提取实验目的、原理、方法、实验内容和思考题。
2. 在该实验的 `preview_report/` 中编写预习报告，内容遵循工作区根目录的 [`preview.md`](preview.md)。
3. 在该实验的 `lab_report/` 中编写实验报告，内容遵循工作区根目录的 [`report.md`](report.md)。
4. 实验报告应包含摘要、关键词、引言、原理、实验、结果与分析讨论、结论和建议、参考文献；有真实数据时，摘要应包含关键数值。
5. `结果与分析讨论` 按定量结果、规律与进一步处理、理论比较、误差来源与改进建议四步组织；使用拟合或不确定度时，保留相应的计算依据和质量指标。
6. 原始数据、实验现象和异常记录如实保留；正文后根据实际数据和教师要求附原始数据、程序或图像等补充材料。缺少材料时明确标注“待补充”，不得编造。
7. 预习报告和实验报告均使用 LaTeX 编写，优先使用 XeLaTeX 或 LuaLaTeX 编译中文文档。Markdown 可以作为中间草稿，但不是实验报告的正式替代品。
8. 编译辅助文件集中放入各实验报告的 `build/`，最终 PDF 与 LaTeX 源文件保存在对应的 `lab_report/` 中；完成后检查编译日志、中文排版、公式、图表、参考文献和 PDF 版面。

## 预习报告要点

预习报告应简述：

- 实验目的；
- 物理原理和实验原理；
- 实验方法与主要实验内容；
- 第一次课后留的问题和实验思考题；
- 对实验的思考、理解以及对实验内容的掌握。

## 实验报告要点

实验报告采用以下结构：

1. 实验题目及学号、姓名、指导教师、实验日期；
2. 摘要（100—200 字，包含目的、方法、主要结果和主要结论；有真实数据时包含至少一个关键数值）；
3. 关键词（3—5 个）；
4. 一、引言；
5. 二、原理；
6. 三、实验；
7. 四、结果与分析讨论；
8. 五、结论和建议（总结）；
9. 六、参考文献；
10. 原始数据、程序或其他补充材料附录（有数据或教师要求时）。

报告中的图、表和公式应统一编号，并标明图表题、物理意义、单位和公式符号。结果讨论应结合图表和文字给出定量结果，分析规律，比较理论预期，说明误差来源，并至少提出两条具体改进建议。使用拟合时应报告拟合关系、参数及 R²、残差或其他适当指标；使用不确定度时应说明计算依据。
