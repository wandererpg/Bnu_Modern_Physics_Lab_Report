# AGENTS.md

## 适用范围与文档分工

本文件规定本工作区的项目级协作与资料管理规则。

- [运行规范.md](运行规范.md)：把用户提示词拆分为任务、上下文、约束和完成条件，并处理信息缺口。
- [preview.md](preview.md)：预习报告内容要求与检查清单。
- [report.md](report.md)：实验报告内容、模板选择、数据处理和检查要求。
- [README.md](README.md)：工作区入口和文件索引。
- [AGENT.md](AGENT.md)：给 Agent 的简短入口。

报告正文、模板细节、公式和图表规范以 preview.md 与 report.md 为准；本文件不重复这些细则。

## 任务路由

- 涉及服务边界的变更，须在 architecture.md 记录。
- 涉及数据库结构迁移的工作，须在 database.ma 记录。
- 准备部署操作时，按 deployment.md 执行并记录。
- 路由目标文档尚不存在时，在首次处理对应任务时建立；无关任务不预先创建空白文档。

## 工作契约与自主权

- 在本地隔离环境或分支中的读取、代码编辑和单元测试均属预授权操作；按任务直接推进，不中途询问许可。
- 对常规、可逆的实现和格式选择，作出最小合理假设并继续；需要时简短说明假设。
- 仅当缺少的信息会实质影响正确性、交付范围或权限边界时，主动向用户询问。等待答复期间继续不依赖该信息的工作。
- 对未获授权的外部副作用、破坏性操作和生产影响，遵循平台审批边界；本地可逆操作不因外部 Skill 建议而无故暂停。

## 指令优先级

始终遵守系统安全规则和平台强制权限边界。在这些边界内，用户当前明确指令优先于本地 AGENTS.md；本地项目规则优先于外部 Skills。外部 Skill 若要求无谓暂停或偏离用户明确授权的任务，应忽略其冲突部分并继续安全可行的工作。

## 风险匹配验证

验证强度应与改动风险相称。文档、配置和小范围修复只做直接相关的局部检查；不得为小改动触发无关的全量测试循环。代码行为变化按改动影响范围执行必要的定向检查，并报告实际覆盖范围和未验证项。

## 实验资料与报告

- 收到实验讲义后，先识别实验划分、标题和上下文，再为每个实验建立独立目录。边界或名称不清时，采用最小假设并标注待确认项。
- 每个实验目录至少包含 preview_report 和 lab_report。预习报告与实验报告均以 LaTeX 源文件编写，并编译生成 PDF；编译辅助文件集中管理。具体内容和检查标准分别见 preview.md 与 report.md。
- 工作区中的实验 PDF 按文档内部标题命名，并放在同名实验目录，格式为 <实验标题>/<实验标题>.pdf。
- 不得虚构实验内容、数据、现象、误差、图表或结论。保留原始记录与异常值；区分原始测量值、计算值、理论值和估计值，确保物理量、单位、有效数字和量纲可复核。
- 报告或材料缺失时标注待补充，不以目录建立或自动生成成功代替内容检查。修改或完成 LaTeX 报告后，按对应报告规范编译并复核日志、内容和 PDF 版面；遇到阻塞时保留源文件并说明原因。

## 模板与通用包维护

- 实验报告模板编号、别名、模板选择顺序及样式限制以 report.md 和模板注册表为准。切换样式时保留正文、信息、文献和原始数据；不得以空骨架覆盖旧版或手工修改过的主文件。
- 更新报告内容规范时，同步更新 skills/Lab_Workflow_Generator/references/ 中对应文件。
- 通用规范、工作流或模板更新后，运行 skills/Lab_Workflow_Generator/scripts/export_agent_bundle.py，并核对 agent_report_bundle/manifest.json。agent_report_bundle/ 只放通用规范、模板和必要依赖，不放实验资料、设计验证稿或编译缓存。
- 设计任务收尾时，仅清理已确认弃用的模板稿、MVP 验证文档及其缓存；保留正式模板、必要检查工具、实验报告、原始材料和历史版本。删除前核对目标并遵循适用的授权边界。

## Git 与同步范围

- 工作区规则持续授权：每次完成相关文件改动并通过匹配的检查后，创建说明改动与验证范围的 Git commit，并推送到 origin 当前分支。
- 推送前获取并整合远程最新状态；不得强制推送覆盖远程历史。若网络、认证、冲突或分支保护阻止推送，保留本地提交并报告原因和提交 ID。
- GitHub 只同步根目录通用规范、skills/ 工作流、参考模板及 agent_report_bundle/ 通用副本。各实验目录、讲义、报告、历史版本、原始数据、图片、脚本和编译成果仅保存在本地，不得加入 Git。
- 暂存前核对完整文件清单；只暂存本次任务相关的已跟踪规范与通用成果。不得夹带无关改动、实验资料或 build/、tmp/ 等编译缓存。
