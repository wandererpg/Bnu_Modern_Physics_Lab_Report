# 训练数据说明（Training Data）

## 1. 数据来源

训练语料来自“近代物理实验I”课程真实报告合集，经筛选后形成：

- **有效样本 17 份**：学生A 7 + 学生B 7 + 学生C 3（2023–2025 学年）
  - 其中**学生A 的 7 份**被指定为**质量金标准**（章节完备、附录含原始数据、误差分析具体到机理）；其实际做法中**未使用 R² 与不确定度**，故本 Skill 将二者设为"使用则须给出"的条件项，而把**相对误差/偏差**列为硬性要求。
- **反面案例 4 份**：反例D（2022–2023 学年），仅用于“不合格特征”检测，不参与风格学习
- **讲义 9 份**：对应 9 个实验，用于公式/常数/方法/拟合/误差规则抽取
- **PPT 要求 1 份**：老师发布的小论文格式要求

## 2. 筛选规则

1. 以 9 份讲义为实验锚点，只保留与锚点主题匹配的报告；
2. 按“作者 × 实验”去重，剔除同名重复文件与嵌套副本；
3. 剔除讲义 PDF、模板、期末总结/论文、非报告论文、LaTeX 源文件、eps/图片/xlsx 素材等；
4. 剔除与 9 个实验无关的近物2报告（法拉第、Hall、拉曼、核磁、SLM、铁磁共振、STM、X 射线、声光、锁相放大等）；
5. 剔除反例D反例（单独登记）。

> ⚠️ 语料中的姓名（学生A、学生B、学生C、反例D等）、教师姓名与学号属于个人信息，公开分发前必须匿名化。

## 3. 风格画像摘要

| 维度 | 结论 |
| --- | --- |
| 章节偏好 | 封面 → 摘要(100–200字) → 关键词 → 引言 → 原理 → 实验 → 结果与分析讨论 → 结论与建议 → 参考文献 → 原始数据附录 |
| 摘要句式 | “本实验利用/采用……测量了……得到……与理论值比较，相对偏差为……”；必须含关键数值 |
| 讨论框架 | 图表定量结果 → 规律与拟合 → 与理论比较解释 → 误差来源 + ≥2 条改进建议 |
| 图表习惯 | 图/表统一编号，图注“图X: 描述”，表格三线表并含单位 |
| 单位与引用 | SI 符号单位；参考文献顺序编号 [1] |
| 术语 | 以“测量”为主（约95%），慎用“测定” |

## 5. 数据使用建议

- **扩展实验**：在 `experiment_library.json` 中新增条目，并在 `style_profile.json` 的 `experiment_mapping` 增加关键词/公式/拟合/误差映射；
- **更换模板**：替换 `style_profile.json` 的 `recommended_chapters` 后重新生成 SKILL.md §2.1；
- **重新训练**：更换 `report/`、`refer/`、`require/` 语料后，重新执行“阶段2 风格分析与知识抽取”流程，再用新 JSON 更新 SKILL.md；
- **保持可追溯**：修改后建议在 README 或 CHANGELOG 记录训练数据版本。
