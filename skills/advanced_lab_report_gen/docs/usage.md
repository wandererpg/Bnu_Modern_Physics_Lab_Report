# 使用指南（Usage Guide）

## 1. 触发方式

在新会话中输入：

```text
/gen_report
```

也可以直接自然语言触发：

```text
使用 advanced_lab_report_gen 生成塞曼效应实验报告。
```

## 2. 输入要求

| 输入 | 格式 | 是否必填 |
| --- | --- | --- |
| 讲义/要求 | PDF（文字层或扫描件均可，扫描件自动 OCR） | 是 |
| 原始数据 | Excel/CSV；也可粘贴文本表格 | 推荐 |
| 范文/模板 | PDF/DOCX | 可选 |
| 封面信息 | 姓名、学号、指导教师、实验日期 | 可选（缺省写“待补充”） |

数据表建议列名包含物理量与单位，例如 `扫场幅度 (V)`、`平均频率 f_avg (kHz)`，便于自动识别与拟合。

## 3. 输出说明

每次生成默认输出三个文件（实验名使用标准名，如 `塞曼效应`）：

```text
outputs/[实验名称]_report.md            # Markdown 源
outputs/[实验名称]_report.pdf           # xelatex 编译结果（若编译成功）
outputs/[实验名称]_generation_log.md    # 生成日志
```

生成日志包含：实验识别结果与置信度、样本状态、数据处理结果、反面风格过滤记录、编译记录。

## 4. 交互流程

1. `/gen_report` 后按引导上传讲义与数据；
2. Skill 输出识别结果（高置信度自动匹配；中置信度请用户确认；低置信度请手动输入）；
3. 样本不足时输出警告（激光模式分析、干涉滤光片）；
4. 自动完成数据处理（拟合、误差、信噪比等）并在日志中给出依据；
5. 按章节/摘要/讨论模板撰写报告；
6. 执行反面风格过滤；
7. 拆分 Markdown 到 lab-assist 接口（00_info / 01_lab_record / 02_summary），xelatex 两遍编译；
8. 输出三个文件。

## 5. 会话示例

```text
/gen_report
我上传了《铷原子的光泵磁共振实验》讲义 PDF 和数据 Excel，请生成报告。
姓名：张三；学号：2025xxxxxx；指导教师：[指导教师姓名]；实验日期：2026-09-08。
```

输出摘要片段示例：

> 本实验采用光抽运与射频磁共振相结合的光泵磁共振技术……拟合斜率 S=25.12 kHz/V（R²=0.99996），计算得 87Rb 朗德因子 g_F=0.499，与理论值 1/2 的相对偏差为 0.20%。

完整示例见 [examples/光泵磁共振实验_报告.md](../examples/光泵磁共振实验_报告.md)。

## 6. 自定义配置

本项目为“自包含 Prompt”，关键规则内嵌于 `SKILL.md`，对应训练 JSON 位于 `training_output/`：

| 想改什么 | 修改位置 |
| --- | --- |
| 章节顺序/字数要求 | SKILL.md §2.1（对应 `style_profile.json` 的 `recommended_chapters`） |
| 摘要模板 | SKILL.md §2.2（`abstract_template`） |
| 讨论框架 | SKILL.md §2.3（`discussion_template`） |
| 实验映射/公式/拟合/误差 | SKILL.md §2.4（`experiment_mapping` + `experiment_library.json`） |
| 全局风格 | SKILL.md §2.5（`global_style`） |
| 反例过滤规则 | SKILL.md §2.6（`excluded_counterexamples`） |
| 摘要字数阈值等硬性检查 | SKILL.md §2.2 与 §步骤5 的检查项 |

修改 SKILL.md 后保存即可；如按“自定义 Skill”安装，需重启会话生效。

## 7. 错误处理

| 异常 | 处理方式 |
| --- | --- |
| 实验识别失败 | 手动输入实验名称 |
| Python 计算失败 | 自动重试 3 次；仍失败标注“待补充数据” |
| PDF 编译失败 | 输出 Markdown 版并附 LaTeX 错误摘要 |
| 反例风格被检测到 | 自动重写并记录到日志 |

## 8. v3.1 口径要点（与老师小论文格式对齐）

- **顶层章节**：摘要 → 关键词 → 一、引言 → 二、原理 → 三、实验 → **四、结果与分析讨论（合并章节）** → 五、结论和建议 → 六、参考文献 → 附录；不得输出独立顶层「结果」「讨论」「实验方法」「数据质量评价」。
- **摘要** 100–200 字（有真实数据时含 ≥1 个关键数值）；**参考文献** 3–6 条。
- **误差与指标**：相对误差/偏差为**硬性**；R²/残差与不确定度为**条件性**（使用则须给出）——与 7 份优秀样本的实际写法一致。
- **附录**统一为「附录 A 原始数据（含教师签名位）＋（若适用）程序/代码附录」。
- **数据溯源声明双落点**：正文封面信息栏下方灰框 ＋ `lab_report/data/README.md`，二者表述须一致。
- **结果层**只陈述事实（含异常点标注）；**讨论层**按四步/五步论证链展开，改进建议 ≥2 条。
