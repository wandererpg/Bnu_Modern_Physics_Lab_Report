# 03 · 校验与验收

「编译通过」≠「报告合格」。LaTeX 对**表格比版心宽**不报错——它直接把表格排到纸外；
对**图在几页之后**也不报错。所以本流水线把验收做成四条可执行判据，全部量**成品 PDF**，
而不是只看源码。

## 1. 四条判据

| 脚本 | 量什么 | 合格线 | 典型耗时 |
| --- | --- | --- | --- |
| `check_report_tex.py` | 源码规则：题注齐全、`\ref` 可解析、必需章节、摘要字数、表格列数/宽度/长小数 | **0 error / 0 warning** | <1 s |
| `check_pdf_geometry.py` | 成品版式：越纸、出血、文字重叠、线条穿字、小字成簇、位图分辨率 | **FATAL 0 / WARN 0** | 2–5 s |
| `check_float_distance.py` | 浮动体与其首次引用相距页数 | **全部 ≤1 页** | <1 s |
| `check_inline_distance.py` | 引用行 → 浮动体内容上沿的**同栏垂直距离** | **全部 ≤60 pt**（实测 22–48 pt） | <1 s |

一次性复核：

```powershell
$S = "$HOME\.codex\skills\Lab_Workflow_Generator\scripts"
python "$S\check_report_tex.py"     lab_report\lab_report.tex
python "$S\check_pdf_geometry.py"   lab_report\lab_report.pdf
python "$S\check_float_distance.py" lab_report\lab_report.pdf
python "$S\check_inline_distance.py" lab_report\lab_report.pdf
```

## 2. `check_report_tex.py`：把写作规则变成检查

| 判据 | 说明 |
| --- | --- |
| 每图每表必须有题注 | 缺 `\caption`/`\bicaption` → error |
| 引用可解析 | `\ref/\eqref` 指向不存在的 label → error；label 从未被引用 → warning |
| 必需章节齐全 | 实验报告：引言/原理/实验/结果与分析讨论/结论/参考文献；预习：目的/原理/仪器/方法/内容 |
| 摘要长度 | 100–200 字（CJK + 数字/字母计数）；`empAbstract` 环境与普通「摘要…关键词」都认 |
| 表格几何 | 列数 >7、自然宽度估算超版心 → warning（**会被排到纸外而编译不报错**） |
| 长小数 | 表格里 ≥8 位未四舍五入的小数 → warning |
| 可读性 | `\resizebox`、插图 <0.85 倍栏宽、题注 <10 字、表格 >20 行 |

`--strict` 让 warning 也计入失败（适合 CI）。`--kind preview` 切换为预习报告规则。

## 3. `check_pdf_geometry.py`：成品 PDF 版式

为什么必须量 PDF：实测一张 10 列表的横线右端到 `x1=1025.6pt`，而 A4 纸宽只有 `595.3pt`——
约 15 cm 内容读者看不到，而编译日志里只有一条 Overfull hbox。

判据（版心边界由文字行的众数边界自动估计，不依赖模板 geometry）：

- **FATAL**：元素越出纸面；
- **WARN**：越出版心（出血）、**通栏长行相互重叠**（如首页"数据说明"框压住摘要首行）、
  **横线/框线从字形中穿过**、图内文字过小（<8 pt 成簇且带图形笔画）、位图有效分辨率 <150 dpi。

两类常见的**非问题**（判据已做区分，不必去改版式）：

- 同一视觉行被字体拆成的碎片（纵向几乎完全重合）——不算重叠；
- 分式的分子/分母（纵向叠得深、横向只交十几 pt）——不算重叠（v1.26 起）。

`--json out.json` 可输出结构化结果，便于接入 CI。

## 4. 让四项通过：版式配方

这是本工作流在真实报告上迭代出来的做法（双栏 `thuemp` 模板）。

### 4.1 浮动体紧跟引用句（最重要）

- **规则 A**：每个图/表的声明**紧跟在首次提到它的那句话之后**，中间不插别的段落；
- **规则 A2**：**一句话只提一个浮动体**。一句话提两个，第二个必然被推到后面（实测距引用 366 pt）；
- 违反这两条时，即使"相隔不到一页"，读者也要往下找——`check_inline_distance.py` 就是量这个的。

### 4.2 正文表：半栏紧凑表

由 `make_data_tables.py --column` 生成（runner 自动传）：

```latex
\begin{table}[H]
  \centering
  \scriptsize
  \setlength{\tabcolsep}{3pt}
  \begin{tabular*}{\columnwidth}{@{\extracolsep{\fill}}...}
```

要点：`[H]`（`float` 宏包的就地放置，不留洞）、`\scriptsize`（半栏 7.5 pt，
可用宽度按 `FIT_EM × 字号 / 7.5` 折算）、`tabular*{\columnwidth}` 让表宽**恰好**等于栏宽。

### 4.3 正文图：按最终尺寸出图

```latex
\begin{figure}[H]
  \centering
  \includegraphics[width=\columnwidth]{figures/xxx.pdf}
  \caption{...}
  \label{fig:xxx}
\end{figure}
```

图用 `figsize` 宽 3.15 in、字号 8–8.5 pt 出图 → 1:1 插入 → 成品里图内文字仍是 8 pt。
通栏大图用 `figure*` + 宽度 ≥0.85`\textwidth`。

### 4.4 首页

首页含题目/作者/数据说明框/中英文摘要，正文容易顶到 `\empfirstfoot` 的
实验时间/报告时间/学号/E-mail 行上。在**正文第一节开头**加：

```latex
\enlargethispage{-3.3cm}
```

### 4.5 反面清单（这些做法试过，都变差）

| 做法 | 实测后果 |
| --- | --- |
| 全局 `\FloatBarrier` + `flafter` + `dblfloatfix` | 页数 13 → **16**，出现 4 处大空白（最大 438 pt） |
| 把浮动体"重新编排"到更靠前的位置 | 末页只剩一行正文（空白 723 pt） |
| 通栏 `cuted` 就地长表 | 放不下时留洞（156 pt） |
| 整篇改单栏 | 版式回到"表格臃肿宽松"，且并不解决紧贴问题 |

**结论**：双栏 + 半栏就地 `[H]` 浮动体 + 声明紧跟引用句，才是既紧凑又无洞的解。
