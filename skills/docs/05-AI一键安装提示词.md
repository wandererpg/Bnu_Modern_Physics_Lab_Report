# 05 · 一键安装提示词（发给你的 AI 助手）

本文件是给**收到本包的人**用的：把下面整段提示词发给 VS Code Codex 插件（或任意支持 Skill 的
Codex/Harness 环境）里的助手，**只改一处**——把 `包路径` 换成自己解压后的实际路径。

> 为什么用"提示词"而不是让人手敲命令：环境差异（Python 在不在 PATH、装了哪个 TeX、Skill 目录在哪）
> 由助手现场判断处理，装完还会跑一遍端到端冒烟测试，比照文档手敲可靠。

---

## 提示词（复制以下全部内容）

```text
【任务】一次性安装并验收「近物实验报告自动化工作流」，装完让它可以直接用。

【背景】
我刚下载并解压了一个包含两个 Codex Skill 的工作流包，解压后的路径是：
    包路径 = D:\近物实验报告自动化工作流_v1.0.0        ← 只改这一行
包内已就位（不要改名、不要移动）：README.md、INSTALL.md、docs/、examples/、
skills/Lab_Workflow_Generator（编排层，目录驱动的工作区引擎）、
skills/advanced_lab_report_gen（文本核心，报告写作规则）、
install.ps1、install.sh、verify_install.py、requirements.txt。

【先读文档再动手】按顺序读 包路径\README.md 的「环境要求/安装/快速开始」三节，
和 包路径\docs\01-工作流总览.md；读完再执行下面步骤。

【按顺序执行，每步先给我一行结论】
1. 核对包完整性：确认 包路径\skills\Lab_Workflow_Generator\SKILL.md、
   包路径\skills\advanced_lab_report_gen\SKILL.md、install.ps1（macOS/Linux 为 install.sh）、
   verify_install.py、examples\demo-单摆法测重力加速度\ 都存在；
   读出 VERSION 和两个 SKILL.md 里的 name/version 报给我。

2. 环境体检：Python ≥3.11；numpy、scipy、matplotlib、pandas、PyMuPDF；
   xelatex；kpsewhich gbt7714-numerical.bst；中文字体（Microsoft YaHei / SimHei /
   Noto Sans CJK 任一即可）。
   - 缺 Python 库：直接用 包路径\requirements.txt 装（python -m pip install -r ...）。
   - 缺 TeX 发行版（xelatex 不存在）：**先别装**，把体积和安装方式告诉我，等我同意
     （几百 MB～几 GB 的系统软件，我不希望你擅自决定）。
   - 缺中文字体：告诉我装哪个包即可，Linux 一般是 fonts-noto-cjk。

3. 安装 Skill：把 skills\ 下的两个目录装到本环境的用户级 Skill 目录
   （默认 ~/.codex/skills，Windows 为 %USERPROFILE%\.codex\skills）。
   - Windows：powershell -ExecutionPolicy Bypass -File "<包路径>\install.ps1"
   - macOS/Linux：bash "<包路径>/install.sh"
   - 若本环境的 Skill 目录不是 ~/.codex/skills（例如工作区级 .agents/skills），
     就装到该实际目录，并在报告里写清你装到了哪里、以及是否需要额外配置才能被识别。
   - 若目标目录已存在同名 Skill：**先问我**要不要覆盖，不要自己加 -Force
     （-Force 会先备份旧版为 *.bak-<时间戳>，可以接受，但要我确认）。

4. 端到端验收（关键一步）：运行
       python "<包路径>\verify_install.py" --demo
   合格标准：汇总行出现 FAIL 0，并且这几个子项都 PASS——
     「demo 端到端跑通：产出 3 页 PDF」、源码检查 0 error、成品版式 FATAL 0 / WARN 0、
     浮动体 ≤1 页、图/表紧贴引用。
   把该脚本输出的汇总（PASS/WARN/FAIL 计数 + 各子项）贴给我。

5. 收尾，明确回答我三件事：
   (a) 两个 Skill 最终装在哪；
   (b) 是否需要"新开一个会话 / 重载 VS Code 窗口"才能让 Skill 生效；
   (c) 我之后做第一个实验的完整操作顺序（讲义放哪、数据放哪、在哪个目录说什么话）。

【硬规则】
- 如实报告：任何一步失败，写清「失败原因 + 你已尝试的修复 + 需要我做什么」；
  禁止用"应该可以了""理论上没问题"收尾。
- 只写这两个 Skill 目录与 Python 包；不要改动我其它目录与文件，
  尤其不要碰我的实验数据、讲义 PDF 与已有报告。
- 需要系统级改动（装 TeX、改 PATH/环境变量、改注册表、删非本包文件）一律先问我。
- Windows 注意：路径含中文或空格时必须加引号；若 py 启动器返回 9009（命令未找到），
  改用 Python 解释器全路径（如 C:\Users\<我>\AppData\Local\Programs\Python\Python311\python.exe）。
- 终端中文乱码时先执行：chcp 65001 与 [Console]::OutputEncoding=[Text.Encoding]::UTF8。
- 输出简洁：结论 + 关键证据；只在失败时贴日志，最多 20 行。

【我接下来会这样用】
把讲义 PDF 放进一个工作区目录 → 让助手用 init_workspace.py 建工作区 →
我把原始数据放进 <实验标题>\data\ → 新开会话说 /build_lab <实验标题> →
助手按文本核心规则写正文、编译 PDF，最后四项校验（源码/版式/浮动体/紧贴度）必须全绿。
如果你愿意，现在就可以先把第一个实验的目录骨架建好等我放数据。
```

## 可选：再加一句"帮我开第一个实验"

装完并**新开会话**后，可以直接说：

```text
帮我建第一个实验：实验名「<讲义首页标题>」，讲义我放在 <讲义目录>。
用 init_workspace.py 建好工作区与 data/ 目录，然后告诉我下一步把哪些数据放进去。
```

## 常见追问（助手可能会遇到）

| 情况 | 处理 |
| --- | --- |
| `xelatex` 缺失，用户不想装 TeX | 仍可完成安装与自检（`verify_install.py` 会把 xelatex 标为 FAIL），但无法产出 PDF；可先用 `.tex` 交付 |
| 公司/学校电脑禁止 pip 安装 | 用 `python -m pip install --user -r requirements.txt`，或让用户联系管理员 |
| Skill 装在 `~/.codex/skills` 但会话里看不到 | 需要**新开会话**（Skill 列表在会话启动时加载）；VS Code 扩展可重载窗口 |
| 用户已有旧版同名 Skill | `install.ps1 -Force` 会先备份为 `*.bak-<时间戳>`，确认后再覆盖 |
