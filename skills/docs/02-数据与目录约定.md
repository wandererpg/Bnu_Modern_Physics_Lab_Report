# 02 · 数据与目录约定

这份约定的目标是：**报告里的每个数字都能追到原始记录，且重跑脚本一定能复现**。

## 1. 数据放哪：`<实验>/data/` 是唯一权威源

```text
<实验标题>/
├── data/                      ← 你放（人也只该改这里）
│   ├── README.md              ← 数据说明（来源/结构/再生方式）
│   └── *.csv
└── lab_report/
    └── data/                  ← 运行期自动镜像（脚本读这里）
```

- runner 每次运行会把 `<实验>/data/*` 镜像到 `lab_report/data/*`（**只增不删**：同名文件大小
  不同才覆盖）；
- 直接改 `lab_report/data/` 里的文件是**无效**的——下次运行会被镜像覆盖；
- 需要"只给脚本看"的中间文件，就让脚本写进 `lab_report/data/`（派生结果本就属于生成物）。

## 2. 原始记录与派生结果分表

| 类型 | 谁产生 | 是否可修改 | 在报告中的位置 |
| --- | --- | --- | --- |
| **原始记录表**（读数、电流、时间…） | 你（手写记录转录） | **绝不修改** | 附录 A「原始数据」 |
| **派生结果表**（平均值、拟合参数、$g$、$B$…） | `generate_plots.py` | 重跑即重生成 | 正文「结果与分析讨论」 |

一次真实运行的教训：只给派生结果表，读者无法核对原始读数（"报告算得出结果，却看不到原始数据"）。
两条都要有，且原始表要能逐项对照照片/记录页。

派生 CSV 与原始 CSV 都要**内容独立**——不要生成两个内容重复的汇总文件，否则附录会出现两张一样的表。

## 3. 命名与表题

- 建议 **`中文名 英文名.csv`**：中文部分 → 表题，英文部分 → `\label{tab:<英文名>}`：

  ```text
  单摆原始数据 pendulum-raw.csv   →  \label{tab:pendulum-raw}
  单摆逐次结果 pendulum-result.csv →  \label{tab:pendulum-result}
  ```

- 表题要写清楚（默认取文件名，往往太短）。用 `lab_report/table_captions.json` 覆盖：

  ```json
  {
    "单摆原始数据 pendulum-raw.csv": "单摆法测重力加速度原始记录：摆长 $L$ 与 50 个周期的累计时间 $t_{50}$（未作任何数值修改）"
  }
  ```

- 表头也可以覆盖（`table_headers.json`），格式同上；
- 表头里可以写数学（`$T^2/\mathrm{s^2}$`）——生成脚本会保留 `$...$` 内的内容不转义；
- **缺测点用 `--`**，生成脚本会识别为缺测（不会当作 0）。

## 4. 数值有效位

- 派生 CSV 里请取 **3–5 位有效数字**后再写文件；`check_report_tex.py` 会对表格里
  ≥8 位未四舍五入的小数报警；
- 不确定度写法：`0.3573±0.0119`（`siunitx` 的 `separate-uncertainty` 已启用）。

## 5. `scripts/generate_plots.py` 规范

数据脚本是**可复现性的载体**，规范如下（也是 `check_report_tex.py` 与人工复核的共同期待）：

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""实验名称：…
数据文件：../data/xxx.csv（读取，不修改）
输出：../figures/*.pdf、../data/<派生结果>.csv
依赖：numpy scipy matplotlib；固定随机种子
"""
import numpy as np
np.random.seed(42)                      # 可复现

# 中文字体（DejaVu 无 CJK 字形，缺字会变方框）
plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei", "DejaVu Sans"]
plt.rcParams["axes.unicode_minus"] = False
COL_W_IN = 3.15                          # 半栏最终宽度（\columnwidth ≈ 3.16 in）

def load_data(): ...                     # 从 ../data/ 读，相对脚本所在目录
def process_data(): ...                  # 计算/拟合/误差传递
def make_figures(): ...                  # 出图到 ../figures/（PDF 优先，dpi=300）
def main():                              # 打印关键结果（斜率/R²/误差）
```

硬性要求：

1. **不写绝对路径**，不修改原始数据文件；
2. 出图按**最终尺寸**（`figsize` 宽 3.15 in 用于半栏、6.5 in 用于通栏），字号 ≥8 pt——
   这样 `\includegraphics[width=\columnwidth]` 1:1 插入后，图内文字仍是 8 pt
   （矢量图被缩小会把字号一起缩小，成品里就成为"看不清的小字"）；
3. 关键结果打印到终端（便于对照正文），并写入派生 CSV；
4. 数值取 3–5 位有效数字。

## 6. `tables/*.tex` 是生成物

由 `make_data_tables.py` 从 `data/*.csv` 生成，**不要手改**（改数据后重跑即可）。默认行为：

- `booktabs` 三线表；数值列右对齐（加 `--array` 则数值列居中、文本列左对齐）；
- **列宽自适应版心**（`--fit`，默认开）：自然宽度超版心时改用 `p{...}` 列；
  `--column` 生成半栏紧凑表（`table[H]` + `\scriptsize` + `tabular*{\columnwidth}`），
  双栏模板下由 runner 自动开启；
- 列数 >7、超长表（>30 行）会被检查脚本提示拆表；
- `--combined` 额外生成 `tables/all_tables.tex`（一次 `\input` 全部表）；
- 自动清理已无对应 CSV 的陈旧表片段（`--no-prune` 可关闭）。

## 7. 数据说明的双落点

数据来源声明要**同时**出现在两处，且内容一致：

1. 正文首页信息栏下方的**灰框**（`\fcolorbox`，见模板前置区）；
2. `<实验>/data/README.md`。

模拟/拟真数据必须写明："正式提交前必须以实测原始记录替换，并重新完成计算、图表与结论。"

## 8. 一个完整的最小例子

见 `examples/demo-单摆法测重力加速度/`：

```text
data/
├── README.md                          # 数据说明（含再生命令与公式）
└── 单摆原始数据 pendulum-raw.csv       # 摆长、50 周期累计时间
lab_report/
├── scripts/generate_plots.py          # 计算 T、T²、逐次 g；拟合 T²–L 得 g
├── table_captions.json                # 两张表的题注
├── lab_report.tex                     # 正文（引用表 1/表 2/图 1）
├── tables/  figures/                  # 生成物
└── lab_report.pdf                     # 3 页，四项校验全绿
```
