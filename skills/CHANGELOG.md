## 编排层 `Lab_Workflow_Generator` 能力演进

> 完整逐条日志见 `skills/Lab_Workflow_Generator/SKILL.md` 的「更新日志」一节。下面是里程碑。

### v1.27 — 新增硬规则「行文不得出现括号」

- **规则**（写进 `references/report.md` §写作风格 与内容核心 §2.5）：旁注并入句子；图表引用写
  “见表 3”；公式引用写“第 2 式”；枚举写“第一，…；第二，…”；小节标题写“一、二、”；
  单位提示写“单位为 m”或表头“…… / A”；不确定度写“标准不确定度为 …”而不是“(1.2345±0.0012) G”；
  **表题与表内文字同样适用**。例外：数学公式内部的分组括号、`\eqref` 编号、代码与文件名。
- **`check_report_tex.py` 新增检查**：扫描 `.tex`（含 `\input` 的表片段）中剩余的 `（…）`/`(…)`，
  告警给出行号与片段。掩码掉注释、代码、数学、`\eqref`、`\texttt{}`；两处掩码细节也一并修好——
  掩码必须**保留换行**（否则行号前移、定位错误）、代码清单的 `caption={…}` **不能掩掉**
  （否则题注里的括号漏检）。
- **实测**：光泵磁共振实验报告（12 页）与预习报告改完后，成品 PDF 全文**全角括号 0 处**
  （106 处半角括号均为公式分组与编号），两文件 `check` 0 error / 0 warning，四项校验全绿。

### v1.26 — 打包前的自查修复（1 处模板 bug + 3 处判据缺陷）

用附带 demo 在干净环境端到端跑通时暴露并修掉：

- **模板 bug**：数据说明框原先写成 `\newcommand{\databox}[1]{...}` 放在 `\twocolumn[...]`
  的可选参数内部，`[1]` 里的 `]` 会提前结束该可选参数 → 编译报
  `Argument of \@newcommand has an extra }`。改为直接用 `\fcolorbox` + `\vspace{4.2em}`。
- **`check_pdf_geometry.py`**：`\frac` 的分子/分母被 PDF 提取成两个"行"，纵向叠得很深、
  横向只交 9.8–16.8 pt，被误报成"两行文字重叠"。新增横向下限 `OVERLAP_DX = 20 pt`。
- **`check_report_tex.py`**：适配 `thuemp` 模板——按 `empAbstract` / `\Keyword` 宏识别摘要与关键词；
  参考文献允许由 `\bibliography` 输出；题注长度改用花括号配对解析（此前含 `$T^{2}$` 的题注
  会被第一个 `}` 截断而误报"题注过短"）。

### v1.25 — 度量口径修正

- `check_inline_distance.py` 改为量**浮动体内容上沿**（图的题注在图下方，量到题注会把图高算成间距，
  把"紧贴"误报为"相距 177pt"；matplotlib 图是矢量嵌入，需同时看 `get_drawings()`）。
- 编号正则加护栏，避免"仪**表 0**.1 A"被当成"表 0"。

### v1.24 — 双栏 + 半栏宽「就地图表」

- `make_data_tables.py` 新增 `--column`：`table[H]` + `\scriptsize` + `tabular*{\columnwidth}` 半栏紧凑表。
- 新增 `check_inline_distance.py`，把"提到图 1 图 1 就紧接在该句之后"变成可量化的验收判据。
- 规则：浮动体声明必须紧跟首次 `\ref` 所在句子的句末；**一句话只提一个浮动体**。

### v1.20 — 原始数据与派生结果分离

用户反馈"报告算得出结果，却无法展示原始数据"，复盘出四条硬规则：

- 原始记录表与派生结果表**分开**，两者都要在报告中出现；
- 表题/表注写清单位与缺测；
- `data/README.md` 与正文数据说明**双落点**声明数据来源；
- 附录表必须**程序化生成**，不手抄。

### v1.1x — 工程化成形

- 工作区目录约定、`init_workspace.py` 批量建工作区、`ocr_lecture.py` 扫描件 OCR；
- `check_report_tex.py`（题注/引用/章节/表宽）、`check_pdf_geometry.py`（成品 PDF 版式）；
- 默认清华 `thuemp` 双栏模板 + 物理学报备选模板；`generation_log.md` 生成日志。

## 文本核心 `advanced_lab_report_gen`

### v3.1 — 对齐老师小论文格式

- 顶层章节「四、结果与分析讨论」为**合并章节**；摘要 100–200 字；参考文献 3–6 条；
- 相对误差为硬性要求；R²/残差与不确定度为"使用则须给出"的条件项；
- 附录统一为「附录 A 原始数据 + 程序附录」；数据溯源声明双落点；
- 移除对特定样本作者的风格加权，改用《大学物理》期刊学术风格作为默认蓝本。

- v3.0：内置训练数据自包含化（部署后不依赖 `training_output/` 下的 JSON）；
- v2.x：9 个近物实验的实验识别映射、数据处理模板、常见写作缺陷的反面案例过滤。
