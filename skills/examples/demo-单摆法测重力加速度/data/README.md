# 数据说明（示例实验：单摆法测重力加速度）

> 这是 **demo 用的演示数据**：由 `T=2π√(L/g)` 取 `g=9.79 m/s²` 反算 50 个周期的累计时间，
> 再加 ±0.03 s 级别的人工扰动模拟读数误差。**不是真实实验记录**，仅用于跑通流程。
> 按本工作流的真实性规则，正式报告必须在数据说明里写明"模拟数据，提交前须以实测记录替换"。

## 测量结构

| 数据 | 结构 | 说明 |
| --- | --- | --- |
| 单摆原始数据 | 5 个摆长 × 各 1 次 50 周期计时 | 摆长 0.500–0.900 m，每次测 50 个周期以减小计时相对误差 |

| `../lab_report/data/单摆逐次结果 pendulum-result.csv` | 由脚本派生的周期 $T$、$T^2$ 与逐次 $g$ | `generate_plots.py` 生成 |

## 再生方式

```bash
python ../lab_report/scripts/generate_plots.py     # 生成 figures/*.pdf 与派生 CSV
```

## 换算与公式

$$T=\frac{t_{50}}{50},\qquad g=\frac{4\pi^{2}L}{T^{2}}$$

以 $T^{2}$ 对 $L$ 作最小二乘直线，斜率 $k=4\pi^{2}/g$，故 $g=4\pi^{2}/k$。
